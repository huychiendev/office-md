# Office to Markdown PRO (High Speed Client-Side)

Gói ứng dụng **Web Tĩnh PRO Độc lập (Standalone)** chạy **100% trên trình duyệt** với tốc độ tức thì.

## Cấu trúc thư mục `pro/`

- `index.html`: Ứng dụng Single Page App Full-Width với Native Instant Client Engine.
- `run_server.py`: Script khởi chạy máy chủ tĩnh cục bộ bằng thư viện chuẩn Python (zero dependency).
- `README.md`: Hướng dẫn sử dụng và triển khai gói Pro.

## Hướng dẫn sử dụng

### 1. Chạy cục bộ một chạm (Local)
Chỉ cần chạy lệnh sau từ thư mục `pro/`:
```bash
python run_server.py
```
Trình duyệt sẽ tự động mở trang `http://localhost:8080`.

### 2. Triển khai Web Tĩnh lên Hosting (Static Hosting)
Upload toàn bộ thư mục `pro/` này lên:
- **GitHub Pages**
- **Cloudflare Pages**
- **Vercel**
- **Netlify**
- **Nginx / Apache / Caddy**

Ứng dụng hoạt động độc lập 100%, không cần cài đặt Python hay bất kỳ backend server nào.
